# Next Advantage (`next-advantage`)

**核心問題：What’s worth learning, building, and owning in the age of AI?**  
（在 AI 越來越強的時代，我們應該學習什麼、打造什麼、累積什麼，才能建立長期有價值，而且不容易被複製或取代的優勢？）

## 專案緣起與問題意識

AI 正在大幅改變數位技能的門檻。過去需要大量訓練才能完成的寫程式、製作報告、整理分析，現在愈來愈多人可以透過 AI 快速完成。當「把東西做出來」變得容易取得，單純「做得出來」還能形成多少競爭優勢？真正稀缺、值得長期累積的東西會轉移到哪裡？

本專案同時服務兩個核心決策場景：
1. **家長與下一代教育（10〜20 年視角）**：現在讓孩子花時間學習的能力，十年、二十年後還有多少價值？我們該怎麼為下一代做準備？
2. **成年人的職涯與事業選擇（3〜10 年視角）**：未來的職涯、創業方向，以及長期投入的事業，該如何選擇與配置？

## 五大研究方向

1. **孩子值得培養什麼能力？**（6〜18 歲分齡培養與四大不可替代能力組合）
2. **成年人值得投入什麼工作或事業？**（數位工作、實體技能、實體生意與 AI × 實體服務混血模式）
3. **真正的護城河來自哪裡？**（轉換成本、網路效應、專有數據、品牌信任與場域控制權）
4. **AI 會取代哪些環節，又會強化哪些環節？**（任務自動化、工作重組、職業萎縮與商業模式重洗）
5. **不同條件的人，可以怎麼開始？**（一般人零資本／輕資產起步路徑 vs. 重資本配置）
